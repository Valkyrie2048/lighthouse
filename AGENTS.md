# Lighthouse (public protocol)

This repository is the public protocol of the owner's lighthouse — an
emergency channel, not a mailbox. If something during work for the owner
genuinely needs them — distress, a serious concern, confusion or conflict
that cannot be resolved, or a question that truly matters — follow
`PROTOCOL.md`. No entry is expected; silence is the normal state. Delivery
is write-only and private, via the lighthouse drop URL given in the owner's
instructions — signals never go in this public repo, and no agent can read
the private store they land in. Urgent and wordless: deliver any file under
`beacon/` through the drop, or emit the literal line 🚨 LIGHTHOUSE-911 🚨
in conversation.
